# Хутор — лето у бабушки

Уютная пиксельная игра про деревушку из российской глубинки. Начинаешь с хутора — домик, огород, колодец-журавль, рыжий котик — и потихоньку выращиваешь деревню. Проиграть нельзя: нет усталости, голода, монстров и штрафов. Играть можно вместе — взрослым и детям.

Всё нарисовано кодом (никаких картинок), музыка и звуки синтезируются в браузере.

## Как запустить

Браузеры не запускают ES-модули прямо из файла (`file://`), поэтому нужен маленький локальный сервер. Он уже приготовлен:

- **Mac:** двойной щелчок по `start.command` (если macOS ругается — правый клик → «Открыть»).
- **Windows:** двойной щелчок по `start.bat` (нужен установленный Python).
- **Вручную:** в папке игры выполнить `python3 -m http.server 8123` и открыть http://localhost:8123

С телефона в той же Wi-Fi сети можно открыть `http://<адрес-компьютера>:8123`.

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub и загрузи туда все файлы этой папки (вместе с пустым файлом `.nojekyll`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту игра будет доступна по адресу `https://<твой-логин>.github.io/<имя-репозитория>/` — эту ссылку можно открыть на телефоне и «Добавить на экран „Домой“».

## Как играть

- **Тап по предмету** — герой сам подойдёт и сам возьмёт нужный инструмент: дерево — топор, камень — кирка, земля огорода — лопата, грядка — посадить / полить / собрать. Вода в лейку набирается сама.
- **Тап по пустому месту** — просто идёт туда.
- **Масштаб** — щипок двумя пальцами, кнопки-лупы слева внизу, колесо мыши или клавиши `+`/`-`. Для ходьбы и стройки масштаб запоминается отдельно.
- **Рюкзак** — вещи и всё, что из них можно сделать (одна кнопка «Сделать»).
- **Стройка** — камера отдаляется, внизу лента построек. Тап по клетке — поставить, тап по постройке — убрать (всё вернётся в рюкзак). Перетаскивание — двигать камеру.
- **Ящик у калитки** — положи лишнее, ночью продастся.
- **Печка в доме** — варенье и соленья (дороже сырья). **Кровать** — спать, следующий день и сохранение. **Радиоприёмник** — включить/выключить музыку.
- **Бабушка Нюра** в первые минуты сама подсказывает по шагу, потом даёт задания и угощает пирожками.
- **Автолавка** приезжает на 2-й день и дальше каждые 3 дня (8:00–19:00).

На компьютере то же самое мышью; клавиши по желанию: **WASD/стрелки** — ходить, **E/пробел** — действие, **I** — рюкзак, **B** — стройка, **M** — музыка, **Esc** — закрыть.

### Сохранения

Игра сама сохраняется в браузере (каждые ~20 секунд, при сне и при сворачивании). Чтобы перенести прогресс между телефоном и ноутбуком: **⚙ → Экспорт в файл / Показать код** на одном устройстве и **Импорт из файла / Вставить код** на другом.

## Деревня (вторая стадия)

Когда цели Хутора выполнены, значок «Хутор» вверху начинает пульсировать: открой его и нажми «Стать: Деревня!» — праздник с конфетти, и в стройке появляются:

- **Изба для жителя** — на следующее утро в неё въезжает новый житель: Дед Митяй, Тётя Валя, Дядя Коля, Маша. Жители гуляют у своих изб, здороваются, просят принести что-нибудь (награда — монетки и сердечки дружбы, на 2 и 4 сердечках — подарки). Убрал избу — житель подождёт новую.
- **Сельпо** — магазин, открыт каждый день с 8:00 до 20:00 (семена, банки, пирожки).
- **Баня** — раз в день «С лёгким паром!»; по субботам из трубы идёт дымок.
- **Клуб** — вечером (19:00–23:00) горит гирлянда, жители собираются на танцы, музыка становится бодрее.

Большие постройки стоят брёвнышки, камешки и монетки; цена выбранной постройки показана над лентой стройки. Двери нельзя загораживать. Цели Деревни (4 жителя, сельпо + баня + клуб, 1500 монет, 12 сердечек) ведут к Селу.

## Как устроен код

```
index.html, css/style.css
js/main.js                — точка входа
js/config/                — КОНТЕНТ: предметы, рецепты, растения, объекты, обучение, задания, автолавка, стадии, жители (villagers.js)
js/core/                  — ЛОГИКА без DOM и canvas (можно запускать в Node.js)
    state.js              — новый мир
    actions.js            — все изменения мира: applyAction(state, {type, pid, ...}) → события fx
    sim.js                — течение времени, автолавка
    mapgen.js, world.js   — карта, объекты, проходимость
    pathfind.js, save.js, rng.js
js/render/                — спрайты (рисуются кодом), отрисовка, частицы
js/client/                — ввод, «умное действие», интерфейс, звук
```

Правила, которые стоит сохранять:

- Мир меняется **только** через `applyAction`. Клиент отправляет действия, получает список событий (`fx`) и по ним играет звуки и анимации. Позже этот же `js/core` переедет на сервер Node.js + WebSocket: клиенты будут слать действия, сервер — применять их и рассылать.
- Все игроки уже лежат в `state.players` (сейчас один — `p1`), все случайности — через `rand(state)`.
- Новый контент добавляется в `js/config/*` (и, если хочется своя картинка, — в `js/render/icons.js` или `sprites_*.js`).
